# Changelog

## [0.0.1] - 2026-09-26

- Target the first coordinated release as 0.0.1.
- Update rustls to 0.23.45 to address RUSTSEC-2026-0285 without advisory exceptions.

- Add worker inventory and pinned repository discovery, recipe selection, source diagnostics and
  reviewed imports into disabled manual targets. Keep selection keyboard focus and mobile reflow.
- Label target execution state explicitly as Enabled or Disabled.

- Redirect development loopback aliases to the configured console before sign-in, and make
  rejected-origin errors show the correct address without weakening mutation checks.
- Add linked software, target, run and release pages; named build and promotion forms; readable
  status, filtering, bounded live logs and visible catalog review.
- Refresh affected views after changes, prefill edit forms, retain navigation on reload, and show
  bounded field diagnostics within active dialogs. Improve keyboard focus and narrow-screen layout.

- Render nested AutoPkg report arrays safely so completed run details and log controls remain
  accessible. The coordinated macOS browser acceptance exercises this with a real AutoPkg report.

- Add an independent self-hosted management console and supported-client session backend.
- Add protected upstream login, expiring server-held sessions, CSRF/origin enforcement, bounded
  gateway operations, restrictive response policies, and role-authoritative management workflows.
- Add resource inspection/action forms, paginated lists/logs, operational summaries, graceful worker
  draining, release withdrawal, credential downloads, and reviewed catalog schema 2 plans.
- Add security/contract tests, cross-repository integration, and hardened deployment examples.
